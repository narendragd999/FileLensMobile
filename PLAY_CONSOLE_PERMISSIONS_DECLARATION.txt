SECTION 1: PHOTO AND VIDEO PERMISSIONS
================================================================================

1. READ_MEDIA_IMAGES (Photos/Images Permission):
-------------------------------------------------
Copy and paste into: "Describe your app's use of the READ_MEDIA_IMAGES permission"

FileLensPro is an offline file search engine and on-device document OCR application. The READ_MEDIA_IMAGES permission is essential for its core functionality:
1. On-Device OCR: Extracting text from document photos, receipts, invoices, and scanned images locally on the device (supporting English & Hindi).
2. Instant Document Search: Indexing and searching image files across device storage by name, metadata, and extracted text.
3. In-App Document Preview: Allowing users to view scanned documents directly inside the app.

All image processing and OCR text extraction occur 100% locally on the user's device and are never uploaded to any external server.


2. READ_MEDIA_VIDEO (Video Permission):
----------------------------------------
Copy and paste into: "Describe your app's use of the READ_MEDIA_VIDEO permission"

The READ_MEDIA_VIDEO permission is required for FileLensPro's core offline search and file management features:
1. Video Search & Indexing: Enabling users to instantly search, filter, and sort video files across all device folders by name, format, date, and file size.
2. In-App Media Management: Allowing users to locate, preview, and organize video files stored across different directories.

All video file operations run completely offline and locally on the device without transmitting any media data externally.


3. "Why can't you use the system Photo Picker?":
------------------------------------------------
Copy and paste if asked:

The system Photo Picker requires manual, single-item user selection. FileLensPro is an automated search and indexing tool that requires batch access to index document images and media files across storage for instant search and offline OCR text extraction.

Full Description:
FileLensPro is a powerful, lightning-fast file search, document scanner, and duplicate file management tool built for Android.

KEY FEATURES:

🔍 Instant Offline File Search:
Search documents, images, PDFs, Excel sheets, videos, and files by name, type, date, or size with instant real-time results.

📄 On-Device OCR (Optical Character Recognition):
Extract text directly from images, scans, and documents offline. Supports English and Devanagari (Hindi) scripts.

✨ Hindi Transliteration & KrutiDev Support:
Search Devanagari text using phonetic English typing and easily convert legacy KrutiDev fonts to Unicode.

📑 PDF & Document Viewer:
Quickly preview PDFs, Word documents (.docx), Excel sheets (.xlsx), and text files right inside the app without external viewers.

🔒 100% Privacy Focused:
All searches, OCR extractions, and file operations run locally on your device. Your personal data and documents never leave your phone.
